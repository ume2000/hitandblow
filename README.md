# ヒット&ブロー オンライン対戦

静的HTMLだけで動作するヒット&ブローです。サーバーは不要で、GitHub Pagesで無料公開できます。

## ファイル構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | **手動接続版(メイン)**。PeerJSも外部サーバーも使わず、ブラウザ標準のWebRTCだけで動作。2人対戦 |
| `peer.html` | PeerJS版(予備)。6桁のルームコードで接続できるが、PeerJSの無料サーバーとCDNに依存する。トーナメントは未完成 |
| `.nojekyll` | GitHub PagesでJekyllの処理を無効にする空ファイル(なくても動作します) |

## 公開方法(GitHub Pages / Deploy from a branch)

1. GitHubで新しいリポジトリを作成する(Publicにする)。
2. このフォルダの**中身**を、`main` ブランチ直下へアップロードする。`index.html` がリポジトリ直下にあることを確認する。
3. `Settings` → `Pages` → `Build and deployment` → `Source` で **Deploy from a branch** を選ぶ。
4. `Branch` を `main`、フォルダを `/ (root)` にして `Save` を押す。
5. 数分待つと、`https://ユーザー名.github.io/リポジトリ名/` で公開される。そのURLを友達に送る。

うまくいかない場合:
- 404になる → `index.html` が `main` 直下にあるか、`Settings` → `Pages` で公開URLが表示されているか確認してください。
- 反映されない → 数分待ち、ブラウザを強制再読み込み(キャッシュなしの更新)してください。
- 無料プランでは、リポジトリをPublicにする必要があります。

## 遊び方(index.html / 手動接続版)

1. **ホスト**が「ルームを作る」を押し、表示された**招待コード**をコピーして友達に送る。
2. **ゲスト**が「入室する」を押し、招待コードを貼り付けて「返信コードを作る」を押す。出てきた**返信コード**をホストに送る。
3. **ホスト**が返信コードを貼り付けて「接続する」を押すと、両者がルーム画面へ進む。
4. ホストが形式(カラー4色/数字4桁)や手数制限を選んで開始する。
5. 相手の答えをHit & Blowで推理して、先に当てた方の勝ち。

## 注意

- ホストまたはゲストがブラウザを閉じると、対戦は終了します。再接続はできません。
- 会社や学校のネットワークなど、環境によってはWebRTCの直接接続が成立しない場合があります。
- 招待コード・返信コードは1回限りです。やり直すときはホストが最初から作り直してください。
- 答えは通信に載せず、対戦終了時にだけ相手へ公開します。
